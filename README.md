### 🗳️ VTB — Vote Through Blockchain
Decentralized voting app built as Backend/Web3 lead on a 4-person team. React + Tailwind frontend (Vercel), Node.js + SQLite + JWT backend (Render), and Solidity smart contracts deployed on the Sepolia testnet via ethers.js. Implemented an HMAC-SHA256 nullifier scheme to guarantee anonymous, one-person-one-vote integrity. Grew into an ongoing initiative with Cluster Madrid & Alastria Blockchain Ecosystem — hackathon-winning and mentored by Alastria engineers.
